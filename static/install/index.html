Install GrapheneOS

Installing GrapheneOS is straightforward and takes only 20 to 30 minutes. Follow this page on a separate computer to prepare your Pixel, install GrapheneOS and get it ready to use.

Installing GrapheneOS resets your Pixel and deletes all data on it. Back up any apps, photos, messages and files you want to keep before you start.

Begin installation ⌄

What you'll need

  • The supported Pixel 6 or later that will receive GrapheneOS
  • A separate computer, phone or tablet to run this installer, with this page open in:
    • Android 14 or later device with Play Protect certification and the Chrome browser
    • Pixel running GrapheneOS with the Vanadium browser
    • Mac with the Chrome browser
    • Windows with the Edge or Chrome browser
  • A reliable USB data cable to connect the two devices directly
  • 32GB of free storage and at least 2GB of free memory on the device running this page

My setup matches this list ⌄

Pixel compatibility

GrapheneOS supports Pixel 6 and later devices, including selected A-series, Pro, Fold and Tablet models. Check the current list of supported Pixels.

  • Avoid carrier-locked Pixels because they may block OEM unlocking.
  • Update the current operating system first when possible. This installer also installs current firmware.
Use Android or GrapheneOS to run the installer

On Android 14 or later with Play Protect certification, use the latest Chrome browser.

On GrapheneOS, use Vanadium and connect the two Pixels directly by USB-C.

  • Use the owner profile and keep the device running this page unlocked
  • Use normal browsing mode, not Incognito
  • Turn off desktop mode
  • Have 32GB of free storage and at least 2GB of free memory
  • Approve reconnection each time your Pixel restarts

Brave also works with Shields disabled. If the browser runs out of memory, use a Mac or Windows computer.

Current supported operating systems

The recommended choices above are the simplest. Current releases of ChromeOS, Arch Linux, Debian, Ubuntu and Linux Mint are also supported. Use an up-to-date operating system, not a virtual machine.

Older end-of-life releases may work but are not supported.

Browser requirements

Use the latest version of:

  • Chromium, except the Ubuntu Snap package
  • Vanadium (GrapheneOS)
  • Google Chrome
  • Microsoft Edge
  • Brave, with Shields disabled for this site
  • On Android, turn off desktop mode.
  • Do not use private browsing.
  • Avoid Flatpak and Snap browser packages because they can block USB access or limit storage.

Allow a new operating system (Step 1 of 8)

  • For a brand-new Pixel, begin setup, choose Set up offline at the first Wi-Fi prompt and skip the optional steps.
  • For a Pixel already in use, back it up to another computer. Installation deletes every app, photo, message and file on the Pixel.

From the home screen:

  1. Connect to Wi-Fi from Settings > Network and internet > Internet. This checks whether the Pixel can be unlocked. You can continue without waiting for updates.
  2. Open Settings > About phone/tablet. Tap Build number repeatedly to enable developer mode.
  3. Search Settings for OEM unlocking, or open Settings > System > Developer options > OEM unlocking.
  4. Turn on OEM unlocking, then power off your Pixel, even if an update is downloading.

I've enabled OEM unlocking ⌄

OEM unlocking isn't available
  1. Open a website to check that Wi-Fi works.
  2. Return to OEM unlocking.

On a Pixel 6a with its original factory software, update to the June 2022 release or later, factory reset the Pixel, reconnect to Wi-Fi and try again.

If it remains unavailable, the Pixel may be a carrier model that blocks bootloader unlocking. This is most common with phones originally sold by US carriers.

  • Check where the phone was first bought.
  • Ask the seller or original carrier whether OEM unlocking is allowed.

A phone that accepts another carrier's SIM can still block OEM unlocking. GrapheneOS cannot bypass this restriction. If the original carrier cannot enable it, return or exchange the phone for a model that allows OEM unlocking. See the device purchasing guidance.

Open Fastboot mode (Step 2 of 8)

Fastboot is the built-in screen used to install an operating system before Android starts.

  1. Turn off your Pixel.
  2. Press and hold the power and volume down buttons together.
  3. Release both buttons when the screen shows a red warning triangle and Fastboot Mode.
  4. Leave your Pixel on this screen. Do not press any buttons.

The Pixel is in Fastboot mode ⌄

If Fastboot mode does not appear
  1. Power off your Pixel.
  2. Hold volume down, then press and hold the power button.
  3. Keep holding both buttons until Fastboot Mode appears.
  4. If Android starts, power off the Pixel and try again.

Connect your Pixel (Step 3 of 8)

  1. Connect your Pixel directly to this device with a reliable USB data cable.
  2. Keep your Pixel on the Fastboot Mode screen.
  3. Do not use a USB hub.

The Pixel is connected ⌄

If your Windows computer does not detect the Pixel

Windows normally uses a built-in Fastboot driver. If the Pixel is not detected:

  1. Leave it connected in Fastboot mode.
  2. Open Windows Update and check for updates.
  3. Open View optional updates.
  4. Install the Android bootloader driver. It may appear as LeMobile Android Device.

If it is not offered, download the Google USB driver and follow Google's Device Manager instructions.

Using Linux? Set up USB access
  1. Install android-udev on Arch Linux or android-sdk-platform-tools-common on Debian or Ubuntu.
  2. Reconnect the Pixel.

These rules give the browser USB access without root.

USB device already in use

fwupd may take the Fastboot connection. Stop it temporarily:

sudo systemctl stop fwupd.service

It starts again after the computer restarts.

USB connection problems
  • Use the USB-C cable supplied with your Pixel when possible.
  • Connect it directly, without a hub.
  • On a desktop computer, use a rear USB port.
  • Try another high-quality data cable or USB port.
  • Close file managers and other apps using the Pixel.
  • For a Pixel Tablet, remove it from its charging stand.
  • If USB remains busy, restart this device and reopen only this page.

Charging-only and faulty cables are a common cause.

Unlock the bootloader (Step 4 of 8)

  1. Click the Unlock bootloader button below.
  2. In the browser prompt, choose your Pixel, then click Connect or Pair.
  3. On Android, approve the USB access prompt.
  4. On your Pixel, the text beside the power button shows the current choice. Press either volume button until Unlock the bootloader appears, then press the power button to select it.

Confirming resets your Pixel and deletes its current data.

If your Pixel is not listed
  1. Keep the Pixel in Fastboot mode and reconnect it directly.
  2. Click Unlock bootloader again.
  3. Choose your Pixel in the browser prompt.
  4. If it is still not listed, use another supported browser or computer.

Download GrapheneOS (Step 5 of 8)

  1. Click the Download GrapheneOS button below.
  2. Wait for the download and verification to finish.

The roughly 2GB download is saved and verified in this browser before anything is sent to your Pixel. It takes a few minutes on fast internet and longer on slow or shared Wi-Fi.

Your browser may not have enough storage for the download. Free some storage or leave private browsing mode before continuing.


Download problems
  • Use a normal browser window.
  • Keep at least 32GB of storage and 2GB of memory free.
  • Close other apps if memory is low.
  • Do not use Flatpak or Snap browser packages.
  • In Brave, disable Shields for this site.
  • Check the internet connection and update the browser.
  • If it still fails, reopen this page in another supported browser.

Install GrapheneOS (Step 6 of 8)

  1. Click the Install GrapheneOS button below.
  2. Keep your Pixel connected and do not use it.
  3. Whenever this page shows Reconnect device, click it, choose your Pixel and click Connect or Pair. On Android, also approve USB access.
  4. Wait for confirmation before continuing.

Installation replaces the Pixel's operating system, takes about 10 to 20 minutes and restarts the Pixel several times.


If installation stops
  1. Do not boot or lock the Pixel.
  2. Return it to Fastboot mode and reconnect it.
  3. If this page was closed or reloaded, download GrapheneOS again.
  4. Repeat the installation.

When installing from Android:

  • Turn off desktop mode.
  • Keep this page visible and the screen unlocked.
  • Approve every reconnection prompt.
  • On a computer, close other apps using USB.
  • Try another cable or direct USB port.

Lock the bootloader (Step 7 of 8)

Do not skip this step. Locking prevents unauthorized changes to the operating system and makes your Pixel verify GrapheneOS whenever it starts. It resets your Pixel again, so do not use it until it is locked.

  1. Click the Lock bootloader button below.
  2. On your Pixel, press either volume button until Lock the bootloader appears beside the power button.
  3. Press the power button to confirm.

If the bootloader does not lock
  1. Keep the Pixel in Fastboot mode and reconnect it.
  2. Click Lock bootloader again.
  3. If the Pixel reports invalid images, repeat step 6 before locking.

Finish setup (Step 8 of 8)

Start and verify GrapheneOS

  1. On your Pixel, press either volume button until Start appears beside the power button.
  2. Press the power button.
  3. At the yellow notice, press the power button once to pause.
  4. Compare the ID with the official hash below.
  5. If every character matches, press the power button again. Then click The hashes match on this page.
  6. If it does not match, leave the notice paused and open More verification details and hashes below.

More verification details and hashes

For the strongest check:

  1. Open this page on a second trusted device.
  2. Find your Pixel in the list below.
  3. Compare its hash with the Pixel's ID.
  • If the hashes still differ, leave the Pixel paused and do not continue setup. Confirm the model and hash again, then ask the GrapheneOS community for help.

The key belongs to the Pixel model, not one GrapheneOS release, so its hash normally stays the same across updates.

Comparing the hash from a second trusted device keeps this check independent of the device used for installation.

Verified boot checks every firmware and operating-system image whenever the Pixel starts. Factory-programmed keys verify the firmware, and the secure element stores the GrapheneOS key used to verify the operating system.

Rollback protection prevents installing an older, vulnerable release. If verified boot finds changed or corrupted data, it rejects it and can use error-correction data to recover the original data.

Hardware-based attestation

Auditor checks the Pixel's hardware, firmware and operating system. Local verification requires a second Android device running Auditor.

The optional monitoring service adds scheduled checks and email alerts. See the Auditor tutorial.

Auditor pins hardware-backed keys during the first verification for later checks. Verify that first pairing carefully because it establishes what the second device will trust.

Success! GrapheneOS is installed and the verified boot key matches.

Welcome to GrapheneOS. Finish setup, then see the usage guide and FAQ.

Complete initial setup

  1. Follow the GrapheneOS setup screens to choose your language and time zone, connect to a network and create a screen lock.
  2. On the final screen, leave Disable OEM unlocking selected. This prevents the bootloader from being unlocked again unless you deliberately re-enable it later.

Help and next steps

If you get stuck, check compatibility, try another USB cable or ask the GrapheneOS community.

Return to the original Pixel operating system

Restoring the original operating system deletes all Pixel data.

  1. Unlock the bootloader and enter Fastboot mode.
  2. Remove the GrapheneOS verified boot key with the button below.
  3. Use Google's web flashing tool to restore the original operating system.

Technical background and alternative steps

Virtual machines

Run the installer directly on a supported operating system. USB passthrough in virtual machines is often unreliable, and virtual machines may have too little memory or storage.

Carrier models

Some carrier variants leave the factory with a carrier identifier that makes the original operating system disable mobile-network and bootloader unlocking. A carrier may be able to remove this restriction. Once OEM unlocking is enabled, GrapheneOS does not use the carrier identifier.

Another way to open Fastboot mode

  • Restart the Pixel and hold volume down until Fastboot Mode appears.
  • Alternatively, hold volume down while connecting a powered-off Pixel by USB.

Why locking matters

With the bootloader locked, someone cannot replace the operating system through Fastboot without first triggering a data wipe. Verified boot also rejects changed data and older, vulnerable releases.

More information about verified boot and Auditor is in verification details in step 8.

Command-line installation

As an alternative to the web installer above, you can use the command-line installation guide. It is intended for technical users who prefer a terminal and requires a supported operating system with suitable Fastboot and OpenSSH packages, along with enough understanding to review the commands before running them.

Use the official guide. Third-party installation instructions are often outdated or incorrect. The web installer above is easier for official releases and does not require additional command-line tools.

If you get stuck, ask the GrapheneOS community for help.
